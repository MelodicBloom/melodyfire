# Decision Log

## Keep the application page encapsulated
**Decision:** Isolate content, components and styles. **Evidence:** Application specificity and existing global identity. **Alternatives:** Adapt global pages; hardcode one component. **Selected path:** Typed content plus `reed-smith` modules. **Why:** Limits regression and makes provenance inspectable. **Tradeoff:** More files. **Confidence:** High. **Revisit condition:** A shared case-study system is commissioned.

## Use notebook geometry rather than spectacle
**Decision:** Paper, graphite, blue-green, ochre, rules and cards. **Evidence:** Requested professional research-lab tone. **Alternatives:** Existing psychedelic identity; animated canvas. **Selected path:** CSS and semantic HTML. **Why:** Legibility and authority. **Tradeoff:** Intentionally less brand continuity. **Confidence:** High. **Revisit condition:** User research shows identity discontinuity harms comprehension.

## Retain contradictions
**Decision:** Render contradiction as a durable synthesis object. **Evidence:** Consensus does not invalidate competing evidence. **Alternatives:** Collapse to one theme. **Selected path:** Dedicated contradiction state. **Why:** Demonstrates judgment and epistemic integrity. **Tradeoff:** More cognitive complexity. **Confidence:** High. **Revisit condition:** Research participants cannot distinguish contradiction from error.

## Use neutral demonstration records
**Decision:** Demonstrate interactions without simulating client data. **Evidence:** No internal research exists. **Alternatives:** Static blank state; fictional realistic records. **Selected path:** Repeated `EXAMPLE` and `DEMONSTRATION DATA` labels. **Why:** Shows the method without fabrication. **Tradeoff:** Less domain realism. **Confidence:** High. **Revisit condition:** Authorized field evidence becomes available.
