## About

Melodyfire is a unified body of creative and technical work at the intersection of:
- Generative AI art & prompt engineering
- Civic technology & regenerative design
- WebGL shaders & interactive web experiences
- Children's illustration systems
- UI/UX design systems

Built with intention, governed by doctrine, and designed to launch itself into independence.

## Tech Stack

- **Frontend:** React 18 + Vite + TypeScript + Tailwind CSS v3 + shadcn/ui
- **Database:** Supabase (PostgreSQL) — project: `ikfejoqvwmmqsuszpdhj`
- **Animation:** Custom Mandala Canvas Engine + CSS scroll-reveal system
- **Fonts:** Clash Display + Satoshi (Fontshare)
- **Deployment:** Vercel · [melodyfire-studio.vercel.app](https://melodyfire-studio.vercel.app/)

## Visual Modes

The site has three distinct visual themes:
1. **Aurora** — psychedelic violet/coral/cyan/gold palette (main)
2. **Solarpunk Grimoire** — deep indigo + gold foil (Regenerative portal)
3. **Holographic** — prismatic glass + iridescent refraction (AI Tools + Reverse Prompt)

## Database Tables

- `user_states` — in-memory session persistence
- `projects` — portfolio projects
- `artworks` — generative art collection
- `services` — service offerings with pricing tiers
- `products` — 21 shop products with Gumroad URLs
- `prompt_sessions` — Prompt Lab usage history
- `reverse_prompt_sessions` — Reverse Prompt Engineer sessions
- `blog_posts` — writing/blog
- `inquiries` — contact/collaboration leads
